# Prompt per il generatore di immagini: trofei di LateBet

## Come usarlo
1. Incolla prima il **PROMPT BASE** (stile comune a tutti).
2. Poi, per ogni trofeo, aggiungi la riga **SOGGETTO** della tabella qui sotto.
3. Salva ogni immagine con il nome della colonna `file` (es. `wins_1000.png`), PNG 1024×1024 con sfondo trasparente.
4. Mandami lo zip: tolgo gli ultimi aloni, li porto a 384×384 e li pubblico (finché non ci sono, l'app disegna un badge provvisorio con lo stesso nome).

## PROMPT BASE (da incollare ogni volta)
> A single game achievement badge, centred, 3D soft-clay / glossy-plastic style like a modern mobile game, thick rounded shapes, gentle bevels, subtle inner highlights and a soft top-left light, rich saturated colours with a darker navy enamel field and a bright metal rim. The badge is a shield or a faceted medal; the subject sits in the middle, big and readable at 64 px. Completely transparent background (alpha), no ground shadow, no text apart from the numbers I ask for, no watermark. Square 1024×1024, subject filling about 85% of the canvas, clean edges with no black outline and no halo.
>
> **Brand element:** the game's logo is a golden analog clock inside a casino-chip ring (dark violet-navy rounded square, gold clock hands, a ring of small dots). Include a small version of that clock-chip as a stamp on the rim or as the centre medallion of every badge, so the whole set feels like one family.
>
> **Rarity (change the metal):** rare = gold rim; epic = icy-blue diamond rim; legendary = platinum + violet gems; mythic = iridescent rose-gold/cosmic rim with tiny stars and a stronger glow.
>
> Style reference: the existing badges of the game (first win, friends 10, level 25, level 50): same thickness, same glossy finish, same palette logic.
